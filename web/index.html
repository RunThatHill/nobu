Nobu Dashboard

Firebase configuration needed

Edit web/firebase-config.js with your Firebase Web App credentials and deploy with firebase deploy.

  1. Create a Firebase project & enable Google Sign-In (Authentication) and Realtime Database.
  2. Paste your Web App config into web/firebase-config.js.
  3. Add your Google email in database.rules.json and deploy rules + hosting.
  4. Set FIREBASE_DATABASE_URL, FIREBASE_CLIENT_EMAIL, and FIREBASE_PRIVATE_KEY in Nobu's .env.
